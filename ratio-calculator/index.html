How Ratio Calculator works

Solve proportions and find a missing value from two equivalent ratios. This section explains the calculation so the output can be checked instead of treated as a black box.

Formula

For a:b = c:x, cross-multiply: a×x = b×c, so x = bc/a.

Worked example

2:3 = 8:x gives x = 3×8 ÷ 2 = 12.

What the inputs mean

This calculator uses First ratio A, First ratio B, Known value C. Enter values in the units shown beside each field; changing a unit without converting the value first can change the meaning of the result.
