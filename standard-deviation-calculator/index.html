How Standard Deviation Calculator works

Calculate population or sample standard deviation from a list of numbers. This section explains the calculation so the output can be checked instead of treated as a black box.

Formula

Population SD uses √(Σ(x−μ)²/N); sample SD uses √(Σ(x−x̄)²/(N−1)).

Worked example

For 10, 12, 14, the population SD is √(8/3) ≈ 1.63.

What the inputs mean
