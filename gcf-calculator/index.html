How GCF Calculator works

Use this free gcf calculator to get a fast estimate in your browser. This section explains the calculation so the output can be checked instead of treated as a black box.

Formula

The greatest common factor is the largest positive integer that divides each input without a remainder.

Worked example

GCF(48,18) = 6.

What the inputs mean

This calculator uses First integer, Second integer. Enter values in the units shown beside each field; changing a unit without converting the value first can change the meaning of the result.
