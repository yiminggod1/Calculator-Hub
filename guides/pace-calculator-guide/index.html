How to Calculate Running Pace

Use total time and distance to calculate average pace per unit of distance.

ADVERTISEMENT

The basic formula

Average pace = total time ÷ distance. If a run takes 30 minutes and covers 3 miles, the average pace is 10 minutes per mile.

Keep units consistent

If time is in minutes and distance is in miles, the result is minutes per mile. If distance is kilometers, the result is minutes per kilometer.

What pace does not tell you

An average pace does not describe changes in speed during a run, terrain, elevation, or interval structure. It is simply the average time per unit distance.
