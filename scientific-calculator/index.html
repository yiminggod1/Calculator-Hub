What this scientific calculator does

Evaluate common scientific expressions without installing software. Use +, -, *, /, parentheses, ^, sqrt(), sin(), cos(), tan(), log(), ln(), and pi. This page also explains the underlying relationship so the number is easier to check rather than treating the result as a black box.

Formula

Expressions are evaluated using standard operator precedence; supported functions include sqrt, trig functions, logarithms, powers, and constants.

Worked example

sqrt(25) + 2^3 = 5 + 8 = 13.
